# EEG & BCI Research Project - Summer 2026

A personal EEG and BCI research project documenting the path from EEG fundamentals to a real-time BCI demo.

## Long-Term Vision

Build toward *NerveGear*: an immersive, responsive brain-computer interface that enables natural interaction between the human brain and digital environments.

## Goal

Build practical foundations in EEG and BCI by:

- Working directly with EEG data using MNE-Python
- Building an EEG classification model
- Developing a real-time EEG streaming pipeline
- Implementing a simple BCI demo
- Documenting experiments, decisions, and results in a reproducible research portfolio

## Roadmap

- Week 1: EEG fundamentals and preprocessing with MNE-Python 
- Week 2: EEG classification
- Week 3: Real-time EEG streaming
- Week 4: BCI demo and portfolio refinement
